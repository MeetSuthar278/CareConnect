# System requirements

## Functional requirements

| User | Requirements |
|---|---|
| Member | Register with verified email, log in, search services, submit and track requests, manage profile, receive notifications and give feedback. |
| Organization | Apply for approval, manage profile, services, capacity and availability, accept or reject referrals, record attendance and completion. |
| Coordinator | Review applications, manage organizations, view and filter requests, review history, manually assign eligible partners and view reports. |
| System | Match eligible organizations, reserve capacity, try backup partners, check deadlines and send notifications. |

## Non-functional requirements

| Area | Requirement |
|---|---|
| Security | Verify identity, check roles and ownership, protect private configuration. |
| Reliability | Save business changes and events together; handle repeated events safely. |
| Usability | Use clear wording, responsive pages and simple forms. |
| Efficiency | Filter and sort in the database before pagination. |
| Maintainability | Use separate modules, documented setup and repeatable tests. |

These are project requirements, not a guarantee of production availability or security.
