# CareConnect – User Stories

**Group 4 | ENSF 607 | University of Calgary**

## 1. Common User Stories

| ID | User Story | Requirement |
|---|---|---|
| US-01 | As a new user, I want to register and verify my email so that I can access the system. | FR-01 |
| US-02 | As a user, I want to log in and reset my password so that I can securely access my account. | FR-02 |

## 2. Community Member

| ID | User Story | Requirement |
|---|---|---|
| US-03 | As a member, I want to manage my profile so that my information stays updated. | FR-03 |
| US-04 | As a member, I want to search services so that I can find suitable support. | FR-04 |
| US-05 | As a member, I want to submit a request with my location and time frame so that I can receive suitable assistance. | FR-05 |
| US-06 | As a member, I want to track my request so that I know its current status. | FR-06 |
| US-07 | As a member, I want to provide feedback so that organizations can understand my experience. | FR-07 |

## 3. Organization Representative

| ID | User Story | Requirement |
|---|---|---|
| US-08 | As a representative, I want to apply for approval so that my organization can participate in CareConnect. | FR-08 |
| US-09 | As a representative, I want to update my organization profile so that its information stays correct. | FR-09 |
| US-10 | As a representative, I want to manage services, capacity and availability so that my organization receives suitable requests. | FR-10 |
| US-11 | As a representative, I want to accept or reject referrals based on my organization's ability to help. | FR-11 |
| US-12 | As a representative, I want to record attendance and completion so that members and coordinators can track service progress. | FR-12 |

## 4. Coordinator

| ID | User Story | Requirement |
|---|---|---|
| US-13 | As a coordinator, I want to review organization applications so that only approved organizations participate. | FR-13 |
| US-14 | As a coordinator, I want to manage approved organizations so that the service network stays reliable. | FR-14 |
| US-15 | As a coordinator, I want to view and filter requests so that I can identify cases that need attention. | FR-15 |
| US-16 | As a coordinator, I want to review referral history so that I can understand how a request was handled. | FR-16 |
| US-17 | As a coordinator, I want to manually assign eligible organizations so that I can help resolve unmatched requests. | FR-17 |
| US-18 | As a coordinator, I want to view reports so that I can understand organization and service performance. | FR-18 |

## 5. Automated System Behaviour

These stories describe automatic system actions from the user's point of view.

| ID | User Story | Requirement |
|---|---|---|
| US-19 | As a member, I want the system to find a suitable organization so that I do not need to contact each organization myself. | FR-19 |
| US-20 | As a representative, I want referrals to consider available capacity so that my organization is not overloaded. | FR-20 |
| US-21 | As a member, I want the system to try another organization if my referral fails so that I have another chance to receive support. | FR-21 |
| US-22 | As a coordinator, I want the system to monitor deadlines so that delayed requests are identified. | FR-22 |
| US-23 | As a coordinator, I want to receive alerts when assistance is delayed or unavailable so that I can take action. | FR-23 |
| US-24 | As a user, I want to receive notifications so that I stay informed about important updates. | FR-24 |
