# User testing guide

Use [the 40-task checklist](ad_hoc_user_testing.csv) with willing classmates. Use synthetic data and approved test accounts.

1. Record an anonymous participant label, role, browser and date.
2. Give the task without explaining which button to press.
3. Observe whether the participant understands the wording and completes the task.
4. Record the actual outcome, pass/fail, issue and suggested improvement.
5. Retest any corrected issue.

Include registration, service search, referrals, coordinator tasks and mobile/keyboard use. Check that preferred time frame is not mistaken for emergency assistance or guaranteed availability.

The exported checklist had no documented participant outcomes. Do not mark tasks as passed based only on automated tests. Keep passwords and personal information out of the records.
