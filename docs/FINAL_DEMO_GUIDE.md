# Final demonstration guide

Open https://careconnect-group4.westus2.cloudapp.azure.com. Obtain passwords privately from the team. Do not display credentials during the presentation.

| Step | What to show |
|---|---|
| 1. Member | Log in, browse services, select a service and submit a request. |
| 2. Matching | Show the request status and the organization selected by the system. |
| 3. Organization | Show the referral notification, respond to an assigned referral, record attendance and completion. |
| 4. Backup | Use a prepared eligible scenario to show rejection and backup matching. |
| 5. Coordinator | Show organization approval, request filters, referral history and reports. |
| 6. Feedback | Show feedback on a completed request. |
| 7. Database | Show the related request, referral, history and outbox records using read-only queries. |

Use synthetic demo records. Matching may select a different eligible organization from the demo login, so check the available offerings and assigned partner before presenting. Do not change live deadlines or reset data to force a result.

Explain how the referral process supports SDG 17 and how the community services support SDG 3.
