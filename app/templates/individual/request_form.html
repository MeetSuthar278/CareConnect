How CareConnect Works

An explanation of the event-driven workflow. These steps are not a live processing monitor.

  1. MemberSubmits a request
  2. Flask APISaves request + outbox event
  3. RabbitMQServiceRequestCreated
  4. Matching workerSelects an eligible partner
  5. RabbitMQReferralCreated
  6. Notification workerStores the organization alert

The status panel reports request state only. A matched request does not confirm notification delivery or service attendance.
